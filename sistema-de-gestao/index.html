perguntas frequentes

Qual a diferença para um sistema pronto?

Um sistema pronto obriga você a se adaptar a ele. O sob medida é feito em volta do jeito que você já trabalha, só com o que você usa.

Dá para começar pequeno?

Sim. Dá para começar com o essencial, como estoque ou caixa, e acrescentar o resto depois.

Preciso instalar alguma coisa?

Não. O sistema funciona no navegador do computador e do celular.

E se eu precisar de uma mudança depois?

Ajustes do dia a dia entram na manutenção mensal. Funções novas são combinadas com você.
